# 系统架构与避障数据流水线

## 1. 分层架构

| 层 | 承载硬件 | 职责 | 开源基础 |
| --- | --- | --- | --- |
| 视觉感知层 | NPU | 障碍物检测、单目深度估计、语义分割 | Ultralytics YOLO + Depth Anything V2 |
| 语义决策层 | GPU | 复杂障碍物的语义理解与避障决策 | MiniCPM-o + llama.cpp（Vulkan） |
| 融合与规划层 | CPU | 高度图注入 costmap、全局与局部路径规划 | Nav2 + slam_toolbox |
| 执行层 | CPU + MCU | 底盘速度闭环、吸尘电机、回充与语音 | OOMWOO 底盘固件 |

## 2. 避障数据流水线

1. 摄像头 RGB 逐帧输入。
2. NPU 执行 YOLO 检测，输出障碍物类别与检测框。
3. NPU 执行 Depth Anything V2，输出单目深度图。
4. 检测框与深度图融合，得到"障碍物框 + 距离"。
5. 深度图转为 2.5D 高度图 / 伪点云，注入 Nav2 costmap，补齐 LiDAR 对低矮与细软障碍的盲区。
6. 2D LiDAR 数据进入 costmap 实时层，负责底层硬避障（不经过 AI）。
7. 遇到线缆、宠物粪便等复杂障碍时，截取 ROI 图像交给 GPU 上的 VLM，输出绕行 / 停止 / 上报，并触发全局重规划。

## 3. Agentic 三要素闭环

| 三要素 | 本项目实现 | 技术手段 |
| --- | --- | --- |
| 多步规划 | 遇障 → 语义识别 → 决策 → 全局重规划 → 继续清扫并更新覆盖图 | VLM 决策 + Nav2 行为树 |
| 工具调用 | 调用摄像头、2D LiDAR、电机、吸尘电机、回充桩、语音播报 | ROS 2 action / service |
| 上下文记忆 | 语义地图（障碍类型、脏污区域）、已清扫覆盖图、障碍类型记忆 | 语义栅格地图 + 状态记录 |

## 4. 关键工程判断

- P1 的 NPU 软件栈对视觉类模型更成熟，大模型端侧推理更稳定的路径是 GPU Vulkan，因此采用"视觉走 NPU、VLM 走 GPU"的分工。
- VLM 只在事件触发时调用，避免持续占用 GPU 影响导航实时性。
- 底层 LiDAR 保证安全兜底，AI 层负责"看得更聪明"，两者在 costmap 层融合。
