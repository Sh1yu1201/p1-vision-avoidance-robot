# 硬件清单与接口连接

## 1. 原型阶段（纯视觉 Demo，可独立演示）

| 设备 | 接口 | 说明 |
| --- | --- | --- |
| 此芯 CIX P1 开发板 | - | 主控，运行全部端侧模型 |
| USB 摄像头 | USB（UVC） | 单目 RGB，建议 1080p / 30fps |
| 散热与电源 | 12V DC | 持续推理时注意散热与功耗余量 |

此配置即可完成"障碍物检测 + 距离估计 + 语义决策"的录屏 Demo，不依赖底盘。

## 2. 整机阶段（接入底盘后）

| 设备 | 接口 | 说明 |
| --- | --- | --- |
| 2D LiDAR | UART / USB | 底层硬避障与建图 |
| 底盘驱动 MCU | UART / CAN | STM32 或 ESP32，接收速度指令 |
| IMU 与碰撞传感器 | I2C / GPIO | 姿态与碰撞反馈 |
| 电源与电池管理 | 12V | 供电与电量回传 |
| 吸尘电机、回充桩、扬声器 | PWM / 串口 | 执行与交互 |

## 3. 数据流与接口约定

- 摄像头 → P1：USB UVC，按帧送入 NPU 推理。
- LiDAR → P1：串口 115200，转为 ROS 2 LaserScan 话题。
- P1 → 底盘 MCU：串口 / CAN 下发速度指令，MCU 负责闭环控制。
- P1 → 语音模块：串口文本转语音，用于"检测到电源线，正在绕行"等播报。

## 4. 上电与联调顺序

1. 单板启动，确认 NPU 驱动与摄像头设备节点正常。
2. 单独运行视觉推理脚本，确认检测框与深度图输出。
3. 接入 LiDAR，确认 costmap 中出现点云与高度图。
4. 接入底盘 MCU，先空转验证速度指令，再落地行走。
5. 整机联调：先直线避障，再贴边绕行，最后覆盖清扫。
